# 04 — Stack VM

**Builds on:** nothing. **Time:** ~45 minutes.
**Done when:** three hand-written bytecode programs print the right numbers.

You write a program that runs other programs. No parsing: the bytecode is a
hand-typed array of numbers. Forty-five minutes, and it demystifies more
than its size suggests.

Do the `--trace` flag. It takes five minutes and makes projects 05-08
debuggable by reading instead of guessing.
