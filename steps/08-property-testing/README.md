# Step 08 — Property-based testing

**Exercises:** 2 (~45 min) · **Project:** your own QuickCheck (~2 h)

Example tests check the cases you thought of. Your bugs live in the ones you
did not. The exercises teach the two halves: generating inputs that actually
hit the edges, and shrinking a failure down to something you can read.

Deliberately placed after steps 02 and 06, so you have a parser and a hash
table to aim it at.
