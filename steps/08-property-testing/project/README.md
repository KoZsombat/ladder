# 11 — Property-based testing

**Builds on:** 01, 10. **Time:** ~2 hours.
**Done when:** your own runner finds a planted bug and shrinks it to a
minimal case.

You write the testing tool, not just tests — a miniature QuickCheck — and
point it at the two things you already own.

Example-based tests check the cases you thought of. Your bugs live in the
ones you did not.
