## Hint 1

method. You will need to import `"bufio"` and `"strings"`.

## Hint 2
```go
sc := bufio.NewScanner(r)
n := 0
for sc.Scan() { n++ }
return n, sc.Err()
```

`TeeCount` is `return io.Copy(w, r)`.
